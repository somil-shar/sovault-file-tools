# sovault-file-tools
SoVault is a fast, privacy-focused client-side web app deployed on Netlify for browser-based file management! 🚀📄  • Features &amp; Tech: Merge, split, compress, &amp; edit PDFs locally using Python, HTML, CSS, JS, PDF.js, PDF-Lib, jsPDF, JSZip, &amp; Canvas 2D with zero telemetry! 🛠️🔒 • URL: https://docukit-file-tools.netlify.app/ 🌐
